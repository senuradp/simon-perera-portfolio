# Senura (Simon) Perera — Portfolio

My personal portfolio showcasing software engineering experience, data science projects, education, and technical skills.

Based in Melbourne, Australia, I’m seeking Junior Software Engineer, Graduate Data Analyst, and entry-level IT opportunities. I have full Australian work rights and am open to relocation within Australia.

## Features

- Responsive desktop and mobile layouts
- Featured software engineering and data science projects
- Searchable project gallery with category filters
- Technologies and skills grouped by area
- Expandable experience sections
- Downloadable CV
- Gmail enquiry drafts for recruitment, freelance work, and research requests

## Built With

- React
- JavaScript
- Vite
- CSS

## Run Locally

Requires Node.js 20.19+ or 22.12+.

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Open the local URL printed in your terminal.

## Production Build

Build the site:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```

The production files are generated in `dist/`.

## Project Structure

```text
public/          Photo and downloadable CV
src.jsx          React components and page content
style.css        Styling and responsive layouts
repos.json       Project gallery data
contact.js       Prefilled email enquiry links
index.html       Page metadata and application entry
vercel.json      Vercel deployment configuration
```

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Select the Vite framework preset.
3. Use `npm run build` as the build command.
4. Use `dist` as the output directory.
5. Deploy.

No environment variables are required.

## Content Updates

- Edit `src.jsx` to update experience, education, and page content.
- Edit `repos.json` to update project titles, descriptions, and links.
- Edit `contact.js` to update email subjects and messages.
- Replace the photo and CV in `public/` when needed.

The repository gallery is a saved snapshot, not a live GitHub feed. Forked repositories are labelled.
